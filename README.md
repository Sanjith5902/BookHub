# Abstract – BookHub
##

This Library Management System is a MERN-stack web application designed to simplify and automate library tasks for both administrators and users. The system provides secure registration and login, book CRUD operations for admins, and searchable browsing and borrowing features for users, with a four-book borrowing limit enforced server-side. MongoDB ensures data persistence, and role-based access separates admin and user privileges. The goal is providing an efficient, user-friendly, and secure platform for managing library resources.
